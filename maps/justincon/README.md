# Justin Con / Bunker Con / Respawn Con

Three suburban houses at night on one street, each hosting a basement LAN party:

- **Bunker Con** (west, green house): a tournament U of dual-monitor tables and a bracket screen.
- **Justin Con** (middle): rows of folding tables, 28 rigs, a neon banner.
- **Respawn Con** (east, yellow house): retro pods of beige CRTs and arcade cabinets.

Tunnels join the basements (Bunker <-> Justin <-> Respawn), with a sign above each door. Every house has a
ground floor, stairs to its basement and cellar stairs from the back yard. A giant wooden effigy burns in the
shared back yard (touching the pyre burns you). Real night skybox, breakable windows, 225 pickups, and every
player spawns with every weapon.

Console: `map justincon`

## Build it

```
make build MAP=justincon && make test MAP=justincon
```
The playable zip lands in `build/justincon/justincon.zip`.
